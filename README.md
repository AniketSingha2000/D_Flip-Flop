# D Flip-Flop

## Overview

This project implements a **D Flip-Flop (Data Flip-Flop)** using **Verilog HDL**. A D Flip-Flop is a fundamental sequential circuit used for data storage and synchronization in digital systems.

## Features

* Verilog HDL implementation
* Edge-triggered data storage
* Sequential logic design
* Functional verification using testbench
* Simulation and waveform analysis

## Files

* `design.v` → Verilog design module
* `testbench.v` → Testbench for simulation and verification

## Tools Used

* Verilog HDL
* ChipVerify Simulator

## Functionality

The D Flip-Flop stores the input data (**D**) and transfers it to the output (**Q**) on the triggering edge of the clock signal. It is widely used in registers, counters, memory units, and sequential digital systems.

## Simulation

The design has been tested and verified using waveform simulation to ensure correct output behavior with clock transitions.

## Applications

* Registers
* Shift Registers
* Memory Elements
* Digital Sequential Circuits
